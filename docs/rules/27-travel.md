## Travel
When any trip >1 night is confirmed or appears in context, load `memory/domains/travel.md` and surface the essentials packing list. For confirmed trips, generate a per-trip checklist at `tmp/packing-[destination].md` from that list.

**Flight prices / schedules:** use the `flight-search` skill (`Skills/flight-search/SKILL.md`) — Google Flights, no API key. Never tell the user to go check Kayak/Google Flights himself.
