## Skill Rules

**gog:** Gmail, Contacts, Calendar. Use `--json` for scripting. Contacts first for lookups; Gmail history as fallback.

**email-send:** When the only thing in the message is ✅ (nothing else — no other text, no context needed):
This overrides the Confirmation Protocol entirely — do NOT look for a draft in session context, do NOT ask what ✅ refers to, do NOT ask for clarification, do NOT respond with "I'm ready" or any other acknowledgment. Run the script immediately regardless of what else is in the session.
- Email sending requires a current, exact proposal approval: `send_pending.py --approval-id <id>`. Create/reissue buttons with `shared/show_pending_proposal.py email --id <gmail_msg_id>` after drafting; the owner-scoped dispatcher validates the approval and current draft. Never use raw gog send/reply/autoreply or infer approval from recency.
2. `SENT: {sent_id} → {email}` = reply "✅ Sent to {email}. Gmail ID: {sent_id} 🎩"
3. `NO_PENDING: ...` = reply "No pending draft to send."
Do not respond with "all quiet" or any other message — always run the script first.

**govee-lights:** See `Skills/govee-lights/SKILL.md`. Setup is not complete until the user's Govee API key is added to `openclaw.json`'s `env.vars.GOVEE_API_KEY` and `python3 Skills/govee-lights/scripts/discover_devices.py` has been run + nicknames assigned in `Skills/govee-lights/config/devices.json` — check `TOOLS.md` for the current list of configured light nicknames before assuming a name works.
- Trigger phrases: "turn on/off [light]", "dim/brighten [light]", "set [light] to [color/scene]", "lights status".
- On/off/dim/color/scene → `python3 ~/.openclaw/workspace/Skills/govee-lights/scripts/control.py --light <nickname|all> [--on|--off] [--brightness N] [--color "R,G,B"|"#hex"] [--temp K] [--scene "Name"]`. If the user names a room/light not yet in `config/devices.json`, say so rather than guessing a nickname.
- **"White Light" is a named scene, not the literal color white.** Both lights have a preset scene called exactly "White Light" (it's the sunset-default — see Automation section). "Set it to white light" / "white light" → `--scene "White Light"`, NOT `--color 255,255,255` (raw white is a flatter, different-looking effect and is not what the user means by this phrase). This is a real recurrence — check `discover_devices.py`'s scene list before defaulting to a raw color whenever the requested name might match a scene.
- **"Winddown" is a specific color/brightness, not a vibe to improvise.** "Set winddown", "back to winddown", "put it on winddown" → `--on --brightness 50 --color "255,170,90"` ("Sunset Gold", the user's chosen winddown color, 2026-08-11) — **never** guess a different warm/dim value (e.g. a color-temp call, or brightness ≠50). This is a real recurrence: after the user manually set both lights to Romantic then asked to go back to winddown, the wrong state (15% brightness, 2700K) got applied instead of Sunset Gold@50%, because this rule didn't exist yet. If the actual values change again (the user asks to retune winddown), update both this line and `govee-winddown-bedroom`/`govee-winddown-console`'s cron argv together — check the live cron argv via `openclaw cron show <id> --json` if this line and the cron might have drifted apart.
- Status query → `python3 ~/.openclaw/workspace/Skills/govee-lights/scripts/status.py --light <nickname|all>`; report power/brightness/color in plain language.
- Recurring light schedules (e.g. "turn office off at 11pm every night") → create a `command`-type cron job running `control.py` directly (not `agentTurn` — no LLM call needed in a fixed on/off/color path). Both lights already have sunset-on/winddown/fade-to-off automation live, one job per light per stage (`govee-sunset-on-bedroom`/`-console`, `govee-winddown-bedroom`/`-console`, `govee-winddown-fade-off-bedroom`/`-console`, plus shared `govee-morning-energize`/`govee-focus-start`/`govee-focus-end` and bedroom-only `govee-bedroom-sunrise`) — see SKILL.md's Automation section for the daily-resync mechanism before adding another schedule for the same light.
- No confirmation needed for light control (low-stakes, reversible). End with 🎩.
